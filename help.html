시험지 사용 설명서

문제를 풀고, 결과와 분석 리포트를 보고, 푼 시험지 사진으로 오답노트를 만드는 방법입니다.

차례
  1. 들어가기
  2. 코드로 문제 풀기
  3. 내 결과·리포트
  4. 오답노트 (사진으로 만들기)
  5. 시험지 만들기
  6. 자주 묻는 질문

1. 들어가기

  1. 사이트를 열면 아이디와 암호를 넣는 화면이 나옵니다. 받은 아이디와 암호를 넣고 들어가기를 누릅니다.
  2. 한 번 들어오면 같은 기기·브라우저에서는 60일 동안 다시 묻지 않습니다.
  3. 암호를 바꾸려면 첫 화면 오른쪽 위의 내 이름을 누르고 새 암호를 넣습니다. 로그아웃도 여기서 합니다.
아이디나 암호를 모르거나 잃어버렸으면 관리자에게 문의하세요. 암호를 여러 번 틀리면 잠시 동안 들어올 수 없습니다.

2. 코드로 문제 풀기

  1. 첫 화면에서 코드로 문제 풀기를 누릅니다.
  2. 받은 5자 코드를 넣습니다. 큰 글자·작은 글자는 구분하지 않습니다.
  3. 문제마다 보기를 눌러 답을 고릅니다. 정답이 여러 개인 문제는 여러 개를 고를 수 있습니다.
  4. 제출하고 채점 보기를 누르면 점수와 틀린 문제, 해설이 바로 나옵니다.
  5. 틀린 문제만 다시 풀기로 복습할 수 있습니다. 다시 푼 결과는 기록에 남지 않습니다.
  6. 응시 화면 위의 인쇄·PDF를 누르면 A4 시험지(한 장에 3~4문항, 마지막 장에 정답표와 해설)가 새 창에 열립니다. 인쇄 창에서 프린터 대신 "PDF로 저장"을 고르면 파일이 됩니다.
  7. 결과 화면의 해설은 접혀 있습니다. 해설 보기(또는 위의 해설 모두 보기)를 누르면 펼쳐집니다. 아래 내 결과·리포트 보기, 오답노트 만들기로 바로 이어서 갈 수 있습니다.
푼 결과로 오답노트 채점 결과 화면의 이 결과로 오답노트 만들기, 또는 내 결과·리포트 표의 오답노트를 누르면 틀린 문제의 원인과 관련 개념을 정리한 오답노트가 만들어져 오답노트 화면에 나타납니다(보통 10분 안, 완료되면 알림). 오답노트 화면을 쓸 수 있는 계정만 가능합니다.
제한 시간·응시 기간 시험지에 제한 시간이 있으면 화면 위에 남은 시간이 표시되고, 시간이 끝나면 자동으로 제출됩니다. 응시 시작 전이거나 마감이 지난 시험지는 코드를 넣어도 열리지 않습니다(안내 문구에 시작·마감 시각이 나옵니다).
풀어야 할 시험 누군가 나에게 시험지를 배정하면 첫 화면 풀어야 할 시험에 나타납니다. 제목을 누르면 코드를 넣지 않아도 바로 열립니다. 첫 화면의 완료율 카드는 배정된 시험 중 몇 개를 풀었는지 보여 줍니다.
기록 제출한 결과는 내 계정에 저장되어 코드를 준 사람도 볼 수 있습니다. 답을 고르지 않은 문제는 틀린 것으로 채점됩니다.

3. 내 결과·리포트

  1. 첫 화면에서 내 결과·리포트를 누르면 지금까지 푼 시험지의 점수·시간이 나옵니다.
  2. 분석 리포트 보기를 누르면 틀린 문제의 원인, 자주 틀리는 유형, 다음에 공부할 것과 연습 문제가 담긴 리포트가 열립니다. "아직 분석 리포트를 받을 수 없습니다"라고 나오면 관리자에게 문의하세요.
  3. 리포트는 새 결과가 생기면 자동으로 다시 만들어집니다. 바로 새로 받고 싶으면 리포트 새로 만들기를 누르세요. 만들어지기까지 보통 10분쯤 걸리고, 준비되지 않았으면 "아직 리포트가 없습니다"라고 나옵니다.
  4. 리포트 화면의 새 창에서 열기로 인쇄하거나 PDF로 저장할 수 있습니다.
  5. 주간 정답률 그래프(최근 8주)와 과목별 정답률·취약 태그가 기록 위에 나옵니다. 시험지에 과목·태그가 적혀 있을 때만 나뉘어 보입니다.
  6. 추천 학습 카드의 이 약점으로 연습 문제 만들기를 누르면 약한 태그를 범위로 AI 문제 만들기 창이 바로 열립니다.
수강 과목 첫 화면 오른쪽 위 이름(또는 아래 계정 탭)을 누르면 수강 과목을 적어 둘 수 있고, 화면 색(밝게·어둡게)도 고를 수 있습니다.

4. 오답노트 (사진으로 만들기)

종이 시험지를 풀고 채점한 뒤 사진을 올리면 정답·해설과 손글씨 메모를 반영한 오답노트가 만들어집니다.

사진 올리기

  1. 첫 화면에서 오답노트를 누릅니다. "아직 오답노트를 쓸 수 없습니다"라고 나오면 관리자에게 문의하세요.
  2. 문제지 이름을 적습니다. 예: 통합과학_2학기_2차. 올린 문제지와 오답노트는 내 계정에서만 보이고, 코드를 준 사람도 볼 수 있습니다.
  3. 사진을 페이지 순서대로 고릅니다. 휴대폰이면 바로 촬영해도 됩니다. 페이지 전체가 들어가고 글씨가 읽히도록 밝은 곳에서 찍습니다.
  4. 올리기를 누릅니다. 보통 10분 안에 처리되고, 목록에 상태가 나옵니다.

손글씨 색깔 약속

색뜻
초록프로그램에게 하는 말. 예: 문제지 위에 적은 진도 범위, "14번 해설 필요", "16번 반응 표 첨부", "19번은 빨간색 대신 파란색 메모를 볼 것"
빨강틀린 답 표시와 왜 틀렸는지 적은 메모. 채점용 동그라미·사선·점수는 자동으로 빼고 읽습니다.
파랑초록으로 "파란색을 볼 것"이라고 적은 문제에서만 빨강 대신 읽습니다.
연필·검정풀이 흔적으로 보고 읽지 않습니다.

확인 질문에 답하기

  1. 글씨가 애매하면 목록에 확인 질문이 표시됩니다. 문제지를 눌러 들어가면 질문과 추정한 답이 보입니다.
  2. 맞는 답을 적고 답 저장을 누르면 다음 처리 때 오답노트에 반영됩니다. 모르면 비워 두어도 됩니다.

오답노트 보기

목록에서 문제지를 누르고 오답노트 보기를 누릅니다. 틀린 문제의 원문 사진, 내 답과 정답, 해설, 내가 적은 원인 메모, 관련 개념이 들어 있습니다. 새 창에서 열기로 인쇄·PDF 저장이 됩니다.

문제지가 "해설 오류 의심" 표시를 달고 있으면, 프로그램이 두 번 풀어 답이 달랐던 문제입니다. 그 문제는 해설을 한 번 더 확인하세요.

5. 시험지 만들기

누구나 시험지를 만들어 코드로 나눌 수 있습니다. 첫 화면의 새 시험지 만들기와 내 시험지를 씁니다.

  1. 새 시험지 만들기 → 제목과 보기(①②③④)를 정하고 문제를 추가합니다. 문제마다 정답을 하나 이상 고릅니다. 과목과 문제별 태그(쉼표로 구분)를 적어 두면 결과 화면에서 과목·태그별 정답률로 나뉘어 보입니다.
  2. 응시 조건에서 제한 시간(분), 응시 시작·마감 시각을 정할 수 있습니다. 비워 두면 제한이 없습니다. 만든 사람은 기간과 상관없이 언제나 열어 볼 수 있습니다.
  3. AI로 문제 만들기를 누르면 범위와 문항 수를 넣어 문제를 자동으로 받을 수 있습니다. 기본은 바로 만들어 주고 고른 문제만 이 시험지에 들어갑니다. 고급(Claude)은 요청만 남기고 닫으면 되고, 보통 10분 안에 검증까지 마친 새 시험지가 내 시험지에 추가되면서 알림이 뜹니다. 고급에서는 사진(교과서·프린트, 최대 8장)을 올려 그 내용으로 문제를 만들 수도 있습니다.
  4. 저장하면 어느 기기에서 들어와도 같은 시험지가 보입니다.
  5. 공유를 누르면 5자 코드가 나옵니다. 이 코드를 푸는 사람에게 알려 줍니다. 시험지를 고치면 다시 공유해야 바뀐 내용이 반영됩니다.
  6. 응시 기록에서 누가 몇 점을 받았는지 봅니다. 내 학생에서는 사람별 기록과 분석 리포트를 봅니다.
  7. 응시 화면에는 시험지를 만든 사람의 이름이 표시됩니다.
  8. 편집 화면 위의 인쇄·PDF로 만든 시험지를 A4 종이 시험지(해설지 포함)로 뽑거나 PDF로 저장할 수 있습니다.
알림 고급 문제 생성, 오답노트 완성, 분석 리포트처럼 시간이 걸리는 일이 끝나면 첫 화면 위쪽 알림에 나타나고 홈 탭에 숫자가 붙습니다. 사이트를 열어 두면 1분 안에, 다시 열면 바로 보입니다. 알림을 누르면 해당 화면으로 갑니다.

6. 자주 묻는 질문

코드를 넣었는데 "등록된 시험지가 없습니다"라고 나와요.
코드를 다시 확인하세요. 만든 사람이 시험지를 지웠거나 아직 공유하지 않았을 수 있습니다.

제출했는데 기록에 없어요.
"틀린 문제만 다시 풀기"로 푼 결과는 기록되지 않습니다. 처음 제출한 결과만 남습니다.

리포트가 안 만들어져요.
결과가 하나 이상 있어야 하고, 만들어지기까지 시간이 걸립니다. 30분이 지나도 없으면 관리자에게 문의하세요.

사진을 올렸는데 계속 "대기 중"이에요.
처리는 정해진 컴퓨터가 켜져 있을 때만 됩니다. 오래 걸리면 관리자에게 문의하세요.

손글씨를 잘못 읽었어요.
확인 질문에 답을 적어 주면 고쳐집니다. 다음부터는 초록·빨강 메모를 채점 표시와 겹치지 않게 적으면 더 정확합니다.

다른 사람이 내 기록을 볼 수 있나요?
코드를 준 사람만 볼 수 있습니다. 그 밖의 사람은 볼 수 없습니다.
